# GiftXIndia™ Premium Corporate Gifting Website

## Files
- index.html — Home
- products.html — Product listing with search and filters
- product-detail.html — Product detail template
- about.html — About us
- catalogue.html — Catalogue request page
- quote.html — Bulk order / quotation form
- contact.html — Contact page
- assets/giftxindia-logo.png — Original supplied logo
- assets/styles.css — Full responsive design
- assets/app.js — Mobile menu, filters, search and demo forms

## Vercel deployment
Upload this project folder to GitHub and import the repository into Vercel.
This is a static HTML website and does not require a build command.
